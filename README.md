# 🏆 من سيربح المليون — تحدي الغرف (PWA)

لعبة مسابقات عربية بأسئلة **جديدة في كل مرة** يولّدها Gemini، وغرف **مالتي بلاير بأكواد** تعمل من أي شبكة، قابلة للتثبيت كتطبيق.

**الرابط:** https://abdallahmohammadshehata-wq.github.io/millionaire-ar-pwa/

## قوانين الغرف
- أول إجابة صحيحة = **+1** وتنتهي الجولة.
- إجابة خاطئة = **−1** ويتقفل السؤال على صاحبها، والفرصة لباقي اللاعبين (الخيار الغلط يتشطب للكل).
- لو كل اللاعبين جاوبوا غلط → سؤال جديد فوراً.
- المهلة: 10 / 15 / 20 / 30 ثانية أو دقيقة. عدد الاختيارات: 2 / 4 / 6 / 8 / 10. عدد الأسئلة: 10 / 15 / 25 / مفتوح.

## التصنيفات والمستويات
10 تصنيفات (تاريخ، جغرافيا، إسلامي، كرة قدم محلي، كرة قدم دولي، مسيرة لاعب محلي، مسيرة لاعب عالمي، رياضة، معلومات عامة، ذكاء IQ)، ولكل تصنيف مستوياته الخاصة من 5: سهل → متوسط → صعب → صعب جداً → أسطوري (تدرّج ألوان من الأخضر للأحمر).

## كيف تمنع اللعبة التكرار وخلط التصنيفات
- كل طلب للذكاء الاصطناعي **لتصنيف واحد فقط**، فلا يمكن أن يظهر سؤال جغرافيا داخل «مسيرة لاعب».
- كل طلب يركز على زاويتين عشوائيتين من قائمة كبيرة لكل تصنيف (مثلاً «الدولة الفاطمية» و«الحرب الباردة»).
- الجهاز يحفظ بصمة كل سؤال ظهر (حتى 5000) وآخر الإجابات لكل تصنيف، ويرسلها للنموذج كقائمة ممنوعات ويرفض أي سؤال مكرر أو معاد صياغته.
- البنك الاحتياطي (228 سؤالاً) يُستخدم فقط عند تعطل الذكاء الاصطناعي.

## الملفات
| الملف | الوظيفة |
|---|---|
| `js/engine.js` | توليد الأسئلة (Gemini)، منع التكرار، البدائل |
| `js/net.js` | الغرف عبر MQTT عام (بدون سيرفر) |
| `js/app.js` | الواجهة، الطور الفردي، منطق المضيف |
| `js/data.js` | التصنيفات والمستويات والجوائز |
| `js/bank.js` | البنك الاحتياطي |
| `.github/workflows/pages.yml` | النشر وحقن مفتاح Gemini من الـ Secret |

## المفتاح
المفتاح **ليس في الكود**. يُحقن وقت النشر من Secret اسمه `GEMINI_API_KEY`:
```
gh secret set GEMINI_API_KEY
```
بما أن الموقع ثابت، المفتاح يظهر في ملف `js/config.js` المنشور؛ يُفضّل تقييده في Google Cloud Console على الدومين `abdallahmohammadshehata-wq.github.io`.

## تشغيل محلي
```
python -m http.server 8080
```
ثم افتح http://localhost:8080 وضع مفتاحك من ⚙️ الإعدادات.
